# Memoo Strimo
Desktop client for the open Stremio addon protocol (Tauri 2 + React + Rust). Ships no content or addons.

Run: `pnpm install && pnpm tauri icon <logo.png> && pnpm tauri dev`   Build: `pnpm tauri build`

Phase 1 (this): Cinemeta browse/search, detail, addon install by URL, parallel stream fetch, parse/trust/score/rank engine, HTML5 playback, watchlist, continue watching, 5 themes, safety filter.
Phase 2: libmpv player, torrent server sidecar, Trakt/TMDB, Live TV + EPG, casting, watch parties, anime room, theme studio.
